Huawei Mirror

A Mac app for controlling a Huawei phone, transferring files, and syncing Arabic text over USB and Wi‑Fi.

  • macOS
  • Swift
  • ADB
  • scrcpy

The problem

I wanted to work with my phone from my Mac, type naturally in Arabic, and transfer files without moving back and forth between screens.

What I built

I combined mirroring, control, file transfers, and screen captures in a Mac app, then added a keyboard mode matching the macOS Arabic layout and two-way clipboard sync with session-only history.

What I tested

I tested clipboard sync with Arabic text on the phone over USB and Wi‑Fi. File imports use SHA‑256 to verify the copy before accepting it.
